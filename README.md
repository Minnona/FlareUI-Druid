# FlareUI Druid

[**Download the latest release**](https://github.com/Minnona/FlareUI-Druid/releases/latest/download/FlareUI-Druid.zip)

A small [FlareUI](https://github.com/malkkav/FlareUI) plugin for WoW Forever. Hides the extra druid mana bar at full mana while shapeshifted and restores it below full, including in combat.

## Install

1. Extract `FlareUI_Druid` from the download into `Interface/AddOns`.
2. Restart WoW and enable **FlareUI Druid**. FlareUI must also be installed.
3. Enable **Mana on Shapeshift** in FlareUI's player-frame Edit Mode settings.

Full-mana hiding is on by default. Modern and FlareUI styles reclaim the hidden bar's space; Forever Style keeps its extra row.

## Commands

- `/fuidruid` — Show the current setting.
- `/fuidruid on` or `/fuidruid off` — Turn full-mana hiding on or off.

Tested with FlareUI 7.0.12. For [bug reports](https://github.com/Minnona/FlareUI-Druid/issues), include your frame style and `/fuidruid debug` output.
